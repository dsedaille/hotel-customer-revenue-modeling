# Hotel Customer Revenue & Behavioral Modeling

## Project Overview

This project uses hotel customer data to analyze customer behavior, identify factors associated with lodging revenue, and build predictive models using statistical and machine learning techniques.

The project emphasizes both model performance and statistical interpretation, including regression assumptions, multicollinearity, residual analysis, feature importance, and model comparison.

## Business Questions

1. Which customer and booking characteristics are most strongly associated with lodging revenue?
2. Can lodging revenue be predicted using customer behavior and reservation characteristics?
3. How do linear regression, regularized regression, and tree-based models compare?
4. Which variables contribute most strongly to customer revenue outcomes?
5. Can customer behavior be used to classify meaningful customer groups or risk patterns?

## Dataset

The project uses a hotel customer dataset containing approximately 83,000 customer records and 31 variables.

The dataset includes customer demographics, booking behavior, lodging revenue, other revenue, stay history, distribution channels, market segments, and special request indicators.
